Архитектура хранения 

OLTP (PostgreSQL): включаем шардирование по author_id (hash-based, 2 шарда).
Каждая подсистема — отдельный логический набор таблиц: Посты, Комментарии, Реакции.

Репликация: RF = 3 (Primary + 2 Standby) для каждого шарда и каждой подсистемы.

Object Storage (Фото/медиа): без шардов в расчёте (разносим бакетами/префиксами на уровне S3), RF = 3.

Носители: NVMe (30 TB, 3000 MB/s, 10k IOPS). В расчётах используем 1 диск на хост (disks_per_host=1).
